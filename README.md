# CSharpToTs

Bridge the gap between your .NET backend and TypeScript frontend by automatically generating TypeScript interfaces from your C# Models/DTOs. Stop manually maintaining TypeScript interfaces that mirror your C# classes!

## Problem It Solves

When building applications with a .NET backend and TypeScript frontend (React, Angular, etc.), you need to maintain TypeScript interfaces that match your C# models. This tool eliminates that manual work by automatically generating and keeping your TypeScript interfaces in sync with your C# models.

## Key Features

- 🔄 Auto-generate TypeScript interfaces from C# Models/DTOs
- 🚀 Real-time updates with watch mode
- ✨ Optional validation schemas (Zod/Yup)
- 🛠️ Simple CLI interface
